# Свадебное приглашение Дарьи и Виктора

Проект перенесен из скачанного сайта, созданного на Tilda, в автономную HTML/CSS/JS-версию.

## Что перенесено

- Обложка приглашения, основной текст, две локации, программа, RSVP-форма и финальный таймер.
- Изображения и иконки сохранены локально в `assets/images` и `assets/icons`.
- Исходные шрифты и музыка хранятся локально в `assets/fonts` и `assets/video`.
- Мобильная композиция собрана по исходным высотам ZeroBlock для ширины 320px с масштабированием до 430px.
- Desktop-экран сохранен как исходная заглушка с просьбой открыть приглашение на телефоне.

## Что удалено

- Служебная разметка и классы Tilda.
- Скрипты, стили, lazyload, animation, forms, stats и ZeroBlock-рантайм Tilda.
- jQuery и статистика Google Tag Manager, подключенная через исходный шаблон.
- Запросы к `tildacdn.com`, `tilda.ws`, `tilda.cc` из рабочей версии.

## Сохраненная функциональность

- Открытие конверта: разъезд створок за 4 секунды и исчезновение печати.
- Анимации появления элементов при скролле через `IntersectionObserver`.
- Фоновая музыка из локального MP3; если браузер блокирует автозапуск, воспроизведение начинается после нажатия на печать.
- Таймер до регистрации: 30 сентября 2026, 17:00 (Новосибирск).
- Встроенная RSVP-форма Яндекс Форм.
- Ссылки на Яндекс Карты для Дворца бракосочетания и ресторана «Шишкин».

## Внешние сервисы

В рабочей версии остались внешние ссылки на Яндекс Карты, а также iframe Яндекс Формы. Для загрузки и отправки анкеты необходим доступ к `forms.yandex.com`.

## Форма

Серверная отправка Tilda удалена. Анкета загружается и отправляет ответы через Яндекс Формы; отдельный серверный обработчик в этом проекте не требуется.

## Запуск локально

```bash
python3 -m http.server 8030
```

После запуска откройте `http://127.0.0.1:8030/` из папки проекта.

Адаптивность проверена на ширинах 320, 375, 390, 430, 768, 1024 и 1440 px.

## GitHub Pages

Загрузите содержимое этой папки в репозиторий и включите GitHub Pages для ветки с сайтом. Основной файл: `index.html`.

## Основные файлы

- `index.html` - семантическая структура страницы.
- `css/reset.css` - базовый сброс.
- `css/style.css` - основной внешний вид и композиции.
- `css/assets.css` - привязка локальных фонов и декора.
- `css/responsive.css` - мобильные и desktop-правила.
- `css/couple.css` - блоки локаций и программы для Дарьи и Виктора.
- `js/main.js` - интерактивность без Tilda.
- `assets/` - локальные изображения и иконки.
